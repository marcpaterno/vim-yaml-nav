*yaml_nav.txt*  *yaml_nav*  YAML navigation plugin

INTRODUCTION                                        *yaml_nav-intro*

Provides navigation among YAML keys at the current indentation level.
Works with both Vim 8+ and Neovim.

**Note:** This plugin is written in legacy Vimscript and is compatible with
both Vim 8+ and Neovim.

COMMANDS                                            *yaml_nav-commands*

*:YamlKeysHere*
    Populate the location list with all keys at the current indentation
    level and open it.
    
    Blank lines and comment lines are excluded from the location list.
    The command is buffer-local and only active in YAML buffers.

MAPPINGS                                            *yaml_nav-mappings*

<leader>k       Calls |:YamlKeysHere|. Configurable; see |yaml_nav-config|.
                Buffer-local; only active in YAML buffers.

CONFIGURATION                                       *yaml_nav-config*

*g:yaml_nav_no_mapping*
    Set to 1 to suppress the default mapping entirely. When set, the
    g:yaml_nav_mapping option is ignored.
    Example: >
        let g:yaml_nav_no_mapping = 1
<
*g:yaml_nav_mapping*
    Override the default mapping key. Default: '<leader>k'.
    Ignored if g:yaml_nav_no_mapping is set to 1.
    Example: >
        let g:yaml_nav_mapping = '<leader>y'
<
